# HydroBot

Portfólio da evolução do HydroBot: V1 (2024), V2 (2025) e V3 (2026).

Site publicado: https://hydrobot-six.vercel.app/

## Executar

Node.js 24.x recomendado.

```bash
npm install
npm run dev
```

```bash
npm run build
npm start
```
